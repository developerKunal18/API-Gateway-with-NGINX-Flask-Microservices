🧠 Why This Is Important

Without an API Gateway:
Client
 ├──► User Service
 ├──► Product Service
 └──► Order Service

Clients need to know every service address.

With an API Gateway:
            Client
               │
               ▼
         NGINX API Gateway
       ┌──────┼──────┐
       ▼      ▼      ▼
 User Service Product Order
    :5001      :5002   :5003

Benefits:
✅ Single entry point
✅ Request routing
✅ Load balancing
✅ SSL termination
✅ Authentication integration
✅ Rate limiting support

Used By :
Netflix
Amazon
Uber
Airbnb
Kubernetes Ingress
